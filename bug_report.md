## 1. Console Warnings & Runtime Errors

### 1.1 [CRITICAL] Convex Mutation Argument & Schema Mismatches
Multiple mutations conflict with `convex/schema.ts`, throwing `ArgumentValidationError`.
- `matches.createMany` misses `matchLabel`, `round`, `matchNumber`.
- `matches.ts` references non-existent tables `scheduleDays` and `locations` (these are arrays inside `tournaments`!).
- `players.remove` passes `id` instead of `playerId`.
- `phases.remove` and `updateStatus` omit `tournamentId`.
- `groups.create` omits `order: v.number()`.
- **Impact:** Nearly all dashboard mutations (creating matches, deleting players, deleting groups) crash with 100% reproduceability.

### 1.2 [HIGH] Convex Query `getByPlayer` Called With `undefined`
In `app/t/[tournamentId]/player/[playerToken]/page.tsx`, `playerId` is passed as `undefined` before data loads. Needs the `"skip"` conditional.

### 1.3 [HIGH] Hydration Mismatch via `localStorage`
`getAdminToken(tournamentId)` runs synchronously during SSR, returning `""`, then hydrating with the real token on the client. Causes layout shift and hydration error.

## 2. Logic Gaps & Missing UI

### 2.1 [CRITICAL] Single Elimination Bracket Progression Broken
`generateBracket` never sets `nextMatchId` and `nextMatchSlot`. Winners of knockout matches never advance.

### 2.2 [HIGH] Bracket Seeding Inverts Tournament Structure
`createSeedPairs` sets Seed 1 to play Seed 2 in Semifinals instead of the Finals.

### 2.3 [HIGH] Dead "Konfiguruj" Button on Phase Cards
The button in `/manage/structure` lacks a `<Link>` or `onClick`. Dead UI.

### 2.4 [HIGH] Broken Logo Link in PublicHeader
Links to `/t/[tournamentId]` instead of `/t/[tournamentId]/public`, returning a 404.

### 2.5 [HIGH] Public Tournament Pages Permanently Disabled
`publicPageEnabled` is set to `false` by default, but there is no toggle UI in `GeneralSettingsPage` to enable it, rendering the entire public module inaccessible to non-admins.

### 2.6 [MEDIUM] Dummy Round-Robin Generator
`structure/[phaseId]/page.tsx` ignores `generateRoundRobin` from `lib/tournament-logic.ts` and runs a hardcoded nested loop, breaking Home/Away balancing and assigning `round: 1` to everything.
